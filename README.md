# 飞凡内部数据平台网页版
Cloudflare 云端验证版 · 0.1.0 · 2026-09-29

供工作室 1—10 人试用：按频道保存标题、缩略图、可获取的 YouTube 数据，查看视频时间轴留存、做频道对比，并限制员工的频道、CTR、收入和导出权限。不会保存视频文件。

**从 [部署教程.md](部署教程.md) 开始。** 双击 [开始部署.html](开始部署.html) 可打开图文配置向导，生成配置文件和初次部署密钥。

如果已经部署，但控制台提示“只有静态资产，不能添加变量 / 绑定”，先读教程开头的修复步骤。当前配置对齐已创建的 Worker **feifanneibupingtai**；部署命令必须使用 **npm run deploy**，构建命令使用 **npm run build**。

## 你已确认的配置
- 尚无域名：先使用 Cloudflare 提供的 workers.dev 网址。
- 管理员邮箱尚未确定：代码中留空，部署时在 Cloudflare 填写。
- 原 feifan-db 已被其他软件使用：本项目新建 feifan-web-db，不能混用。
- 代码目录不含本地授权、Google 密钥、采集数据或 node_modules。

## 首版已实现
频道和视频目录分页；缩略图文件存 R2；20 类 API 报表选项；独立覆盖面日报；时间轴留存曲线、区间提示和候选峰值；CSV 导入；频道同周期对比；任务分批、持久进度与手动恢复；备注标签；后端权限与审计；CSV、原始报表和频道 JSONL 导出。

## 交付状态
本地类型检查、Cloudflare 打包和 21 项测试通过。测试使用本地 D1 / R2 与模拟 Google 响应；包含 18 频道分页、52 视频分页、OAuth 状态与 PKCE、任务重复投递及权限验证。真实账号授权、Google 指标资格和正式 Cloudflare 运行仍需按教程验收。这里的“20 类”是可请求的报表选项，不代表每个频道都能返回全部数据。

这不是“删除频道后永久保留所有 API 数据”的已完成方案。API 保存受授权及刷新/删除规则约束；自动周期复核、撤权清理、完整备份恢复、既有本地数据库迁移尚未完成。要删除频道，请先完成独立归档验收，不能只凭任务显示完成。详见教程中的边界说明。

## 本地运行（可选）
安装 Node.js 24，在本目录打开终端：

~~~powershell
npm ci
npm run dev
~~~

打开 http://127.0.0.1:8890。只监听本机，自动生成 .dev.vars 和本地模拟存储；本地会以测试管理员进入，请勿把本地服务暴露到外网。真实 Google 数据仍需单独配置网站 OAuth。再次上传时不要带上 .dev.vars、.wrangler 或 node_modules。

~~~powershell
npm test
npm run check-upload
~~~

上传检查用于干净发布目录；本地运行后存在 .dev.vars 时会主动报错提醒，不要为通过检查删掉仍在用的密钥。

## 项目结构
- public：网页界面、图表、部署向导
- src：Worker API、身份验证、Google OAuth、队列、SQL 表结构
- scripts：生成配置、本地启动、发布文件检查
- tests：本地隔离测试
- cloudflare.config.json：填写新数据库的完整 UUID，其他名称可保持默认
- package-lock.json：锁定依赖版本，应一起提交
